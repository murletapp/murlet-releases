# Guardigan

Guardigan is a free network video recorder for macOS. It records your
security cameras and understands what's happening, entirely on your Mac.

This repository hosts Guardigan's releases and issue tracker.

[Download the latest release](https://github.com/guardigan/guardigan-releases/releases/latest)

Requires an Apple silicon Mac running macOS 12 or later.

More at [guardigan.app](https://guardigan.app).

## Bugs and support

Something broken? [Open a bug report](https://github.com/guardigan/guardigan-releases/issues/new/choose).

Anything else? support@guardigan.app.
