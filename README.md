# Murlet

Murlet is a free network video recorder for macOS. It records your
security cameras and understands what's happening, entirely on your Mac.

This repository hosts Murlet's releases and issue tracker.

[Download the latest release](https://github.com/murletapp/murlet-releases/releases/latest)

Requires an Apple silicon Mac running macOS 12 or later.

More at [murlet.com](https://murlet.com).

## Bugs and support

Something broken? [Open a bug report](https://github.com/murletapp/murlet-releases/issues/new/choose).

Anything else? support@murlet.com.
